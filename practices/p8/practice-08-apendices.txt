APENDICES - PRACTICA 08
MIGRACION INTEGRAL DE POSTGRESQL

============================================================
APENDICE A - HERRAMIENTAS ALTERNATIVAS
============================================================

Metacomandos de psql:

\l+     Lista bases de datos.
\dn+    Lista schemas.
\dt+    Lista tablas.
\df+    Lista funciones.
\des+   Lista servidores extranjeros.

Consultas de catalogos:

pg_database    Bases de datos.
pg_roles       Roles.
pg_class       Relaciones.
pg_proc        Funciones y procedimientos.
pg_tablespace  Tablespaces.
pg_constraint  Restricciones.
pg_trigger     Triggers.

Herramientas de migracion:

pg_dumpall     Objetos globales.
pg_dump        Respaldo logico de una base.
pg_restore     Inspeccion y restauracion de respaldos.

============================================================
APENDICE B - NOTAS DE SEGURIDAD
============================================================

1. --no-role-passwords omite los verificadores de contrasenas.

2. No es suficiente restaurar los nombres de los roles
   cuando una conexion FDW requiere autenticacion.

3. Las credenciales deben gestionarse por separado.

4. No se deben imprimir contrasenas ni verificadores
   en las evidencias de capacitacion.

5. La corrida de laboratorio presento inicialmente:

   password authentication failed for user "p8_reporter"

6. La credencial se corrigio posteriormente sin volver
   a restaurar las bases.

7. La comprobacion final registro:

   CREDENCIALES_EQUIVALENTES=1
   FDW_FILAS|2
   ADAPTACION_FDW=PASS

============================================================
APENDICE C - INTERPRETACION DE OBJETOS
============================================================

SCHEMA:
Agrupa objetos dentro de una base.

TABLE:
Tabla convencional.

TABLE DATA:
Contenido de una tabla incluido en el respaldo.

SEQUENCE:
Generador de identificadores.

SEQUENCE SET:
Estado del generador restaurado.

VIEW:
Vista convencional.

MATERIALIZED VIEW:
Vista materializada.

MATERIALIZED VIEW DATA:
Datos persistidos de la vista materializada.

FUNCTION:
Funcion almacenada.

PROCEDURE:
Procedimiento almacenado.

TRIGGER:
Objeto que responde a determinados eventos.

CONSTRAINT:
Restriccion de integridad.

INDEX:
Indice.

ACL:
Permisos asociados a objetos.

EXTENSION:
Extension PostgreSQL.

SERVER:
Definicion de un servidor externo.

USER MAPPING:
Asociacion de usuario local con servidor externo.

FOREIGN TABLE:
Definicion de tabla remota.
