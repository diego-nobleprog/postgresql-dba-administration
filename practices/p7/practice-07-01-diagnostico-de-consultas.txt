PostgreSQL DBA Administration
Rendimiento y diagnostico

OBJETIVO

Interpretar estimaciones, filas reales, tiempos y buffers; comparar la misma consulta antes y despues de crear un indice.

REQUISITOS

Laboratorio nuevo preparado mediante 07.00.
Contenedor p7-performance-manual preparado mediante 07.00.
No ejecutar sobre el contenedor temporal usado durante el desarrollo.
Cada escenario se ejecuta una sola vez sobre su carga.

ACTIVIDADES DEL SCRIPT

1. Crear orders_01 con 200000 filas y analizar su distribucion.
2. Consultar 20 pedidos del cliente 4242 sin indice secundario.
3. Comparar EXPLAIN con EXPLAIN ANALYZE, BUFFERS y SETTINGS.
4. Crear un B-tree sobre customer_id y repetir la consulta.
5. Comparar los planes JSON y consultar pg_stat_statements.
6. Eliminar el indice experimental y comprobar la carga.

EJECUCION - POWERSHELL

& {
    $ErrorActionPreference = "Stop"
    $name = "p7-performance-manual"

    $raw = @(docker inspect $name)
    if ($LASTEXITCODE -ne 0) { throw "No se encontro el contenedor." }
    $info = @(($raw -join [Environment]::NewLine) | ConvertFrom-Json)[0]

    if ($info.Config.Labels.'nobleprog.p7.lab' -ne "true") {
        throw "Etiqueta incorrecta."
    }
    if (-not $info.State.Running) { throw "El contenedor no esta activo." }

    docker exec -u root $name bash /tmp/p7-scripts/01-query-diagnosis.sh
    $runCode = $LASTEXITCODE

    $token = [guid]::NewGuid().ToString("N")
    $destination = Join-Path (Get-Location).Path "temp\p7-01-$token.txt"
    New-Item -ItemType Directory -Path ".\temp" -Force | Out-Null

    docker cp "${name}:/tmp/p7-01-results.txt" $destination
    if ($LASTEXITCODE -ne 0) { throw "No se pudo recuperar la evidencia." }

    if ($runCode -ne 0) {
        throw "Escenario fallido. Revisar evidencia y no repetir."
    }

    $lines = @(Get-Content -LiteralPath $destination -Encoding UTF8)
    if ($lines -notcontains "PASS: ESCENARIO 07.01 COMPLETADO") {
        throw "Falta la confirmacion final."
    }

    Write-Host "Evidencia: $destination"
}

INTERPRETACION DBA

Distinguir costo estimado de tiempo medido. Los buffers hit y read describen accesos a buffers; shared read no demuestra por si solo una lectura fisica del dispositivo. No exigir un factor fijo de aceleracion.
