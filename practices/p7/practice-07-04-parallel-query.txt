OBJETIVO

Comparar ejecucion serial y paralela, verificando trabajadores lanzados y resultados calculados.

REQUISITOS

Laboratorio preparado y recursos nuevos para 07.04.
Contenedor p7-performance-manual preparado mediante 07.00.
No ejecutar sobre el contenedor temporal usado durante el desarrollo.
Cada escenario se ejecuta una sola vez sobre su carga.

ACTIVIDADES DEL SCRIPT

1. Crear parallel_data_04 con 600000 filas.
2. Registrar la configuracion inicial.
3. Medir serial, paralelo, paralelo y serial.
4. Comprobar conteo, suma de identificadores y calculo del payload.
5. Inspeccionar Gather, agregacion parcial y Workers Launched.
6. Consultar una clave primaria selectiva permitiendo paralelismo.
7. Verificar configuracion final y contadores CPU del contenedor.

EJECUCION - POWERSHELL

& {
    $ErrorActionPreference = "Stop"
    $name = "p7-performance-manual"

    $raw = @(docker inspect $name)
    if ($LASTEXITCODE -ne 0) { throw "No se encontro el contenedor." }
    $info = @(($raw -join [Environment]::NewLine) | ConvertFrom-Json)[0]

    if ($info.Config.Labels.'nobleprog.p7.lab' -ne "true") {
        throw "Etiqueta incorrecta."
    }
    if (-not $info.State.Running) { throw "El contenedor no esta activo." }

    docker exec -u root $name bash /tmp/p7-scripts/04-parallel-query.sh
    $runCode = $LASTEXITCODE

    $token = [guid]::NewGuid().ToString("N")
    $destination = Join-Path (Get-Location).Path "temp\p7-04-$token.txt"
    New-Item -ItemType Directory -Path ".\temp" -Force | Out-Null

    docker cp "${name}:/tmp/p7-04-results.txt" $destination
    if ($LASTEXITCODE -ne 0) { throw "No se pudo recuperar la evidencia." }

    if ($runCode -ne 0) {
        throw "Escenario fallido. Revisar evidencia y no repetir."
    }

    $lines = @(Get-Content -LiteralPath $destination -Encoding UTF8)
    if ($lines -notcontains "PASS: ESCENARIO 07.04 COMPLETADO") {
        throw "Falta la confirmacion final."
    }

    Write-Host "Evidencia: $destination"
}

Ejecutar desde la raiz del repositorio.
No introducir este bloque dentro de psql.

RESULTADOS Y VERIFICACIONES

Cuatro mediciones de agregacion y una selectiva. Las pruebas paralelas deben lanzar trabajadores. La selectiva utiliza la clave primaria sin Gather. Los resultados directos son iguales.

INTERPRETACION DBA

Permitir paralelismo no obliga a usarlo ni garantiza menor tiempo. Relacionar tiempos con trabajadores reales, limites CPU y throttling. PGOPTIONS afecta solo a cada conexion de medicion.
